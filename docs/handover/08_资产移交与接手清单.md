## 5. 资产核验操作

在交出和接收两侧分别执行文件 SHA256 检查。macOS 可用：

```bash
shasum -a 256 path/to/report.xlsx
shasum -a 256 path/to/checkpoint.json
git rev-parse HEAD
git status --short
```

Linux 可用 `sha256sum`。以 proof/证据索引给定哈希核对，不仅核对文件大小和名称。大 checkpoint 的哈希读取需要时间，但比运行到一半才发现复制不完整更易定位。

运行资料含产品定义、模型返回和分析假设，应按项目现有资料权限交接。API key、授权头和个人配置不作为运行证据分发。不要为了制作“完整备份”直接把整个工作区连同 `.env`压缩上传。
